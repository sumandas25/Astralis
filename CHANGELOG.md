# Changelog

All notable changes to Astralis will be documented in this file.

## v1.0.0 - Initial Public Release

- Published Astralis as an open source astronomy encyclopedia and cosmic atlas.
- Added curated astronomy objects, mission pages, search, filtering, comparison, and detail views.
- Added Research AI chat support with server-side provider configuration for Gemini, OpenAI, Lovable, or custom OpenAI-compatible APIs.
- Added Supabase-backed auth and community/forum routes.
- Added resilient image loading and fallbacks for external astronomy media.
- Added GitHub community files, CI, security policy, contribution guide, and Vercel deployment support.
- Deployed the live app to Vercel: https://astralis-ten.vercel.app/
